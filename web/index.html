设计你的 Agent

Soul · 角色与表达 定义它是谁、重视什么，以及用怎样的语气与你交流。
Skill · 做事方法 写明什么时候使用和工作步骤；任务不匹配时可以不使用。
内部 ID 保持稳定；改名不会丢失 Skill。
Agent 根据能力说明和使用条件判断是否加载。
Memory · 长期记忆 只有你确认的内容，才会在相关的新对话中被读取。

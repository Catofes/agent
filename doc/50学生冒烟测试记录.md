# 50 学生冒烟测试记录

## 2026-08-06 本地 fake LLM 基线

- 命令：`make smoke`
- 覆盖：50 名学生登录、保存 Soul/Skill/工具设计、新建对话、计算器工具回环、并发聊天、教师锁定、锁定后拒绝模型请求、学生 SSE 断线重连和权威快照恢复。
- fake LLM：每次调用延迟 15 ms，每名学生执行两次模型迭代（发起工具调用 + 根据工具结果回答）。
- 应用模型并发上限：8。
- 机器：AMD Ryzen 7 5700G，8 核/16 线程，124 GiB 内存，Linux 6.17.13-2-pve x86_64。

| 指标 | 结果 |
| --- | ---: |
| 总耗时 | 2.362 s |
| 聊天 P50 | 489 ms |
| 聊天 P95 | 794 ms |
| 流程错误 | 0 |
| HTTP 5xx | 0 |
| `database is locked` | 0 |
| LLM 调用 | 100 |
| LLM 错误 | 0 |
| 实际最大 LLM 并发 | 7 |
| 最大 goroutine | 263 |
| Heap 变化 | +2,373,888 bytes |

结论：本地 fake LLM 基线在 50 学生单轮并发下通过，未出现 HTTP 5xx、SQLite 锁错误、超出模型并发上限或锁定后继续调用模型。
